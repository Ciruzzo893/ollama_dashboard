# Ollama AI Dashboard

Questo è un dashboard per interagire con l'AI Ollama.

## Funzionalità

- Interfaccia web per chattare con l'AI
- Visualizzazione dei modelli disponibili
- Monitoraggio dello stato del sistema

## Installazione

1. Clona il repository
2. Installa le dipendenze con `pip install -r requirements.txt`
3. Configura i servizi systemd
